# IT Set Desk — MCP Server

بيخلّي **Claude** (وأي برنامج بيدعم MCP) يقرا ويشتغل على التذاكر والأصول والصيانة الوقائية في IT Set Desk، بصلاحيات مفتاح API انت اللي بتعمله.

مثلاً تقدر تقول لـ Claude:
- "إيه التذاكر المتأخرة عن الـ SLA؟ ورتبهالي بالأولوية."
- "اعملي ملخص للاجتماع الصبح: المفتوح، المتأخر، وضغط الشغل على كل فني."
- "افتح تذكرة لهالة من الإدارة: البروجكتور في قاعة B مش بيعرض، واربطها باللابتوب LAP-0012."
- "الطابعة PRN-003 حصلها كام عطل؟ والضمان بتاعها لسه شغال؟"
- "اكتب رد مهذب لصاحب التذكرة ITS-1024 بالعربي، وسجّل 20 دقيقة شغل."

## الأدوات (12)

| الأداة | بتعمل إيه | الصلاحية |
|---|---|---|
| `itsd_get_overview` | ملخص لوحة التحكم: المفتوح، المتأخر، الالتزام بالـ SLA، الحمل على الفنيين، والصيانة والضمانات | قراءة |
| `itsd_search_tickets` | بحث وفلترة: الحالة، الأولوية، النوع، المسؤول (`me`)، الجهاز، الـ SLA، والصيانة الوقائية | قراءة |
| `itsd_get_ticket` | تذكرة كاملة: المحادثة، الـ Checklist، الوقت، والروابط | قراءة |
| `itsd_search_assets` / `itsd_get_asset` | سجل الأصول، والضمان، وMTTR/MTBF، والتاريخ، والتذاكر | قراءة |
| `itsd_list_maintenance_plans` | خطط الصيانة الوقائية وميعادها الجاي | قراءة |
| `itsd_search_kb` | قاعدة المعرفة | قراءة |
| `itsd_list_reference` | الفنيين، والفرق، والتصنيفات، ومقدمي الطلبات | قراءة |
| `itsd_create_ticket` | فتح تذكرة. الأولوية بتتحسب من مصفوفة ITIL | قراءة وتعديل |
| `itsd_update_ticket` | تغيير الحالة، المسؤول، الأولوية، التصنيف، أو الجهاز | قراءة وتعديل |
| `itsd_add_comment` | رد لصاحب الطلب أو ملاحظة داخلية | قراءة وتعديل |
| `itsd_log_work` | تسجيل وقت شغل | قراءة وتعديل |

**مفيش أداة بتمسح أي حاجة.** كل حاجة بتتعمل بتتسجّل في سجل التدقيق باسم صاحب المفتاح.

## الإعداد (5 دقايق)

### 1) اعمل مفتاح API
- **من فين:** IT Set Desk ← **الإعدادات ← مفاتيح API** ← اكتب اسم للمفتاح (مثلاً "Claude على لابتوبي") ← اختار الصلاحية والمدة ← **إنشاء مفتاح**.
- **الصلاحية:**
  - **قراءة فقط:** Claude يسأل ويلخّص ومايقدرش يعدّل أي حاجة. **ابدأ بده.**
  - **قراءة وتعديل:** يفتح تذاكر، ويرد، ويغيّر الحالة.
- **انسخ المفتاح فوراً.** بيبدأ بـ `itsd_` ومش هيظهر تاني.
- **المفتاح بيشتغل بصلاحياتك انت:** مفتاح الفني ما يقدرش يعمل حاجة الأدمن بس هو اللي يعملها.

### 2) انسخ ملفين على جهازك
من فولدر `mcp/bundle/` انسخ:
- `itset-desk-mcp.mjs`
- `core.cjs`

حطهم في فولدر واحد، مثلاً `C:\itset-mcp\`. محتاج **Node.js 20 أو أحدث** بس، من غير `npm install`.

### 3) وصّله بـ Claude

**Claude Desktop:**
- افتح ملف الإعدادات:
  - Windows: `%APPDATA%\Claude\claude_desktop_config.json`
  - macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- ضيف الإعداد ده:

```json
{
  "mcpServers": {
    "itset-desk": {
      "command": "node",
      "args": ["C:\\itset-mcp\\itset-desk-mcp.mjs"],
      "env": {
        "ITSET_DESK_URL": "http://helpdesk.company.local:8080",
        "ITSET_DESK_TOKEN": "itsd_..."
      }
    }
  }
}
```

- اقفل Claude Desktop وافتحه تاني. هتلاقي أدوات `itset-desk` في قايمة الأدوات.

**Claude Code:**
```bash
claude mcp add itset-desk \
  -e ITSET_DESK_URL=http://helpdesk.company.local:8080 \
  -e ITSET_DESK_TOKEN=itsd_... \
  -- node /path/to/itset-desk-mcp.mjs
```

| المتغير | القيمة |
|---|---|
| `ITSET_DESK_URL` | عنوان IT Set Desk زي ما بتفتحه في المتصفح، من غير `/` في الآخر |
| `ITSET_DESK_TOKEN` | المفتاح من الخطوة 1 |

- **لو السيرفر HTTPS بشهادة داخلية:** ضيف `"NODE_EXTRA_CA_CERTS": "C:\\certs\\company-ca.pem"` في `env`.

## الأمان
- **المفتاح بيتحفظ في السيرفر كـ hash بس،** ومش بيظهر غير مرة واحدة.
- **المفتاح ما يقدرش:** يغيّر كلمات السر، أو يعمل أو يلغي مفاتيح، أو يصدّر أو يستورد البيانات، أو يلمس النسخ الاحتياطية.
- **المفتاح "قراءة فقط"** أي محاولة تعديل بيه بترجع خطأ واضح.
- **إلغاء أي مفتاح** من الإعدادات بيوقفه فوراً. وتعطيل الفني أو سحب دخوله بيلغي مفاتيحه كلها.
- **المحاولات الغلط بمفاتيح مش صحيحة** بتتقفل تدريجياً لكل IP.
- **البيانات بتعدّي على Claude:** أي حاجة Claude بيقراها، زي أسماء الموظفين وإيميلاتهم ونص التذاكر، بتتبعت للنموذج علشان يرد. لو عندك بيانات حساسة، استخدم مفتاح قراءة فقط لفريق محدد، وراجع سياسة الشركة قبل ما تفعّله.

## للمطوّر
```bash
cd mcp
npm install
npm run build          # dist/ (TypeScript → JS) + نسخة من ../public/core.js
npm run smoke          # بيشغّل Desk تجريبي، يعمل مفاتيح، ويختبر الـ 12 أداة كأنه Claude
npm run bundle         # bundle/ = ملفين بيشتغلوا من غير npm install
npm run smoke:bundle
```
- **SDK:** مبني على `@modelcontextprotocol/server` v2 (الإصدار المستقر) وZod 4. الاتصال stdio.
- **منطق مشترك:** حسابات الـ SLA والأصول والصيانة جاية من نفس `core.js` بتاع Desk، فالأرقام نفس اللي في الواجهة.
- **التقييم:** `evaluation.xml` فيه 10 أسئلة على البيانات التجريبية الإنجليزي لاختبار جودة استخدام النموذج للأدوات.

## اللي مش موجود (لسه)
- **مفيش اتصال من claude.ai على الويب.** الـ Custom connector هناك محتاج سيرفر HTTP عام وOAuth. الإصدار ده stdio للاستخدام من Claude Desktop وClaude Code على جهاز في نفس الشبكة.
- **مفيش رفع مرفقات، ولا تشغيل خطط الصيانة، ولا تعديل الأصول من خلال Claude.**
